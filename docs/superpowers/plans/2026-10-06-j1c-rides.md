# Rides Fixes (J1c) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rides get their two peaks (driver found, driver here), a face and a plate wherever a driver appears (live ride and الرجعة request board / demand claim), a search with a visible finish line and a 3-minute "try the other vehicle" offer, an SOS sheet that leads with the police call, and a flag (not a house) for ride destinations.

**Architecture:** Pure logic first (moments, feedback, search stages, offer timing, pin kind), each with a vitest test, then the screens read it. Money stays on the server: the 3-minute offer is a new pair of orders procedures (`orders.rideSwitchQuote`, `orders.switchRideVehicle`) that re-quote the other vertical with `PricingService` and, on the customer's confirmation, cancel the searching ride (free, before a match) and place the new one in one unit of work. Pushes mirror the two moments through two new notify templates. The SOS sheet keeps one shared component (`packages/ui`) with a `layout="rider"` prop so the Partner app is unchanged.

**Tech Stack:** Zod + tRPC contracts (`packages/contracts`), NestJS API (`apps/api`), Expo customer app (`apps/customer`), shared UI (`packages/ui`), copy (`packages/i18n`), vitest.

Spec: `docs/specs/2026-10-05-customer-joy.md` §2 (J-D7) and §5.1 (Rides: f4, f5, f6, f9); findings `docs/research/ui-ux-audit/2026-10-05-joy/3-live-moments.md` L-02, L-03, L-06, L-15, L-16, L-17 and `4-rajaa-wallet-account.md` R-01, R-02 (C-19, C-34).

**Before you start:** another session works on maps (`packages/map/**`, map feature folders, zones). Check `git log --oneline -20` before each task; skip anything already built. Stage only the files each task names.

## What already exists (checked 2026-10-06)

- `moments.ts` knows food only (`accepted | picked_up | near | delivered`); `playCue` is gated by quiet days (`season.sounds`).
- `customer_coming_out` is a chat quick reply (`QUICK_REPLIES`), so «طالع هسة» sends it through `chat.send` like the sheet's quick replies.
- Nearby vehicles (`dispatch.nearby`, `NearbyVehicles`) exist on the choose screen only; the live search map has the radar but no cars and frames the whole route.
- `customerFreeCancelAfterSec = 180` is in the city dispatch config (`config.city`), and the orchestrator stops the search at that moment (`onFreeCancel` → needs dispatcher). There is no switch-vehicle procedure.
- Notify has no ride-matched or driver-at-pickup template.
- `SAFETY_RULES.policeNumber` is the one named constant for 104; `SosSheet` also defaults to a literal `'104'` (removed here).
- الرجعة offers carry only `driverId`; `routes.driverCards` serves departures only.

## Decisions taken in this plan

1. **Quiet days**: no moment sound (already true through `playCue`), and the "matched" buzz becomes a plain `medium` instead of the celebratory `success`. The driver-here buzz is a functional alarm and stays.
2. **Status for 4 s**: "matched fresh" is measured from the server's `trip.acceptedAt`, so opening the push within 4 s also shows «لگينالك سايق».
3. **Push text without the plate**: notify lookups have no vehicle read; the push names the driver, the app card shows the plate. (Logged as a deviation; a vehicle lookup can follow.)
4. **Switch offer conditions** (server): a ride, the orderer, still `placed`, no driver on the trip, no extra participants (rides booked for someone else keep searching), and at least `customerFreeCancelAfterSec` since placement (`ride_switch_unavailable` otherwise). The re-quote uses the customer's door-pickup choice, remembered with the ride memo. The client sends the fare it showed; a different server fare is `price_changed`.
5. **Request-board driver card**: first name (identity vault, purpose `intercity_driver_card`), today's check-in and car from the driver's latest departure, photo null until public portraits exist. No rating yet (no rating source for الرجعة drivers; deviation).
6. **«فريق درايفر»**: the shared `sos.*` strings and the customer الرجعة strings say «فريق درايفر»; partner-only strings (`partner.*`, `console.*`) keep «الديسباتشر».
