# Driver (درايفر) — Console Spec

Date: 2026-10-03 · Status: approved — Plan 9 complete.

Web console (Next.js, RTL, role-based navigation): dispatch, support, finance, ops, analytics, system/admin.

## Dispatch board
Layout: live map (right two-thirds) + queue panel (left third).
Map: online drivers as dots coloured by state (free / offered / on job / over cap / recently offline), tier ring; active trips as lines; zones shaded by demand; restaurants as pins with prep load; garages with departure counts. Hover: name, vehicle, score, cash held, current job. Click: driver drawer with assign / message / call / suspend.
Queue columns: يبحث (wave countdown, +500 flag) · معروض (unanswered offers) · مُعيَّن (ETA vs promise) · يحتاج موزّع (no acceptance, unreachable customer, failed substitute auction, departure low-fill) — red with sound. Drag a card onto a driver to assign.
Policy switches per vertical (broadcast / auto / suggest-only) with config values visible; changes logged.
Garage view: boards for البوابة ١، البوابة ٢، السوق، النهضة; demand per window; "call a driver against demand" opens the vetted list.
Right-now bar: orders/hour, active drivers, avg time-to-accept, late orders, cash in field, outbox health.

## Support desk
Unified inbox (in-app + WhatsApp), AI first line with handoff summaries, urgency-ranked queue, one-case screen (order, trip map, participants, ledger lines, all messages, scores, suggested resolution), canned Iraqi-Arabic responses with one-tap actions, escalation rules, resolution survey, merchant and driver support in the same desk.

## Finance
Ledger explorer, driver balances and caps, settlement channels (ops round, ZainCash matching, agent shops), restaurant payouts and statements, nightly close report, promotions spend vs incremental orders, points liability.

## Ops
Onboarding and document review, zones and tier editor (polygons), landmarks and meeting points approval, pricing tables with simulator, promotions builder and approvals, catalog taxonomy, staff and roles.

## Analytics
Orders, rides, seats, khat by zone/time; driver and merchant scorecards; funnel from search to order; shadow-metered vs zone prices; demand heat; week-one launch metrics.

## System / admin
Health, outbox, jobs, audit log of every console action, vault access log, data export per user, feature flags and config per city.
